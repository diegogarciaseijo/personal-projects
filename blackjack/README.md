# Blackjack

A simple command-line Blackjack game written in Python.

## Description

This program simulates a basic game of Blackjack between a player and a dealer. The player can choose to hit or stand, while the dealer automatically hits until reaching 17.

The program uses a shuffled deck of 52 cards and correctly handles aces as either 1 or 11 depending on the hand's value.

## Features

- Randomly shuffled 52-card deck
- Player can hit or stand
- Dealer automatically hits until reaching 17
- Correct handling of aces
- Win, lose, and tie detection

## What I Learned

- Using lists to store and manage data
- Using `random.shuffle()` to randomly shuffle a list
- Using `list.pop()` to remove and retrieve elements from a list
- Working with strings and the `isdigit()` method
- Using functions to organize code and reuse logic
- Using loops and conditional statements to control game flow
- Handling different possible values for aces in Blackjack

## Note

This is a simplified version of Blackjack and does not include advanced rules such as splitting, doubling down, or insurance.
