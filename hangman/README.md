# Hangman

A command-line implementation of the classic Hangman game written in C.

## Features

- Random word selection
- Hidden word display
- Input validation
- Case-insensitive letter guessing
- Repeated letter detection
- Lives system
- Win and lose conditions

## Concepts Practiced

- Arrays
- Strings
- Functions
- Loops
- Random number generation
- Boolean logic
- Character handling with `ctype.h`

## What I Learned

This was my first larger personal project in C. It helped me practice working with strings, arrays, functions, loops, random number generation, and game logic on my own.
